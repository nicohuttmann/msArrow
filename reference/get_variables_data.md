# Return variables data

Return variables data

## Usage

``` r
get_variables_data(which, variables, dataset, as_arrow_table = F, ...)
```

## Arguments

- which:

  which variables data columns to pull (multiple supported)

- variables:

  (optional) vector of variables or expression

- dataset:

  dataset

- as_arrow_table:

  return an arrow table

- ...:

  additional arguments to open_data()
