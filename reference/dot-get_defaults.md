# Returns a default column set used by the DIA-NN importers

Returns a default column set used by the DIA-NN importers

## Usage

``` r
.get_defaults(type, name)
```

## Arguments

- type:

  default set to return ("variables_data" or "data_frames")

- name:

  name of a single default within

## Value

the requested defaults, or the whole list if is missing
