# Writer function for get_data_frame

Writer function for get_data_frame

## Usage

``` r
.cat_get_data_frame_m(copy2clipboard = T, graphics = F, change_output.type = F)
```

## Arguments

- copy2clipboard:

  copy the code to the clipboard

- graphics:

  use a graphical interface for selection

- change_output.type:

  change output type to other than "tibble"
