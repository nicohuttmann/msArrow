# Same as strsplit but option to return as vector and to convert to numeric

Same as strsplit but option to return as vector and to convert to
numeric

## Usage

``` r
strsplit_(x, split, vector.output = T, as_numeric = F)
```

## Arguments

- x:

  string

- split:

  split character

- vector.output:

  output type (T = vector; F = list)

- as_numeric:

  try to convert to numeric
