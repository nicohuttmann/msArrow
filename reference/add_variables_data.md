# Add variables data to data frame

Add variables data to data frame

## Usage

``` r
add_variables_data(data, which, by = "variables", dataset)
```

## Arguments

- data:

  data frame

- which:

  variables data columns to add

- by:

  column of the variables data to join on (default "variables")

- dataset:

  dataset

## Value

the data frame with the requested variables data columns added
