# Writer function for get_observations_data

Writer function for get_observations_data

## Usage

``` r
.cat_get_observations_data(
  copy2clipboard = T,
  graphics = F,
  change_output.type = F
)
```

## Arguments

- copy2clipboard:

  copy the code to the clipboard

- graphics:

  use a graphical interface for selection

- change_output.type:

  change output type to other than "tibble"
