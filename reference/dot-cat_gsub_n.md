# Substitutes pattern multiple times and prints output as code

Substitutes pattern multiple times and prints output as code

## Usage

``` r
.cat_gsub_n(x, pattern, replacement, sep = "\n\n")
```

## Arguments

- x:

  character string containing pattern to be substituted

- pattern:

  character pattern to be substituted

- replacement:

  character vector of strings to use for substitution

- sep:

  separator string between n outputs
