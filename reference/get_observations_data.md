# Return observations data

Return observations data

## Usage

``` r
get_observations_data(which, observations, dataset, as_arrow_table = F, ...)
```

## Arguments

- which:

  which observations data columns to pull (multiple supported)

- observations:

  (optional) vector of observations or expression

- dataset:

  dataset

- as_arrow_table:

  return an arrow table

- ...:

  additional arguments to open_data()
