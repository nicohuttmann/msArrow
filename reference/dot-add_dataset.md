# Registers a new dataset and creates its folder layout

Registers a new dataset and creates its folder layout

## Usage

``` r
.add_dataset(name, save_dir, replace = F)
```

## Arguments

- name:

  name of the dataset

- save_dir:

  folder the dataset store is created in (default: tempdir())

- replace:

  replace an existing entry of the same name without warning

## Value

TRUE (invisibly)
