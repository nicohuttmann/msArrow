# Performs strsplit and keeps first n elements of each string

Performs strsplit and keeps first n elements of each string

## Usage

``` r
strsplit_keep_firstn(x, split, n = 1, as_numeric = F)
```

## Arguments

- x:

  vector

- split:

  separator

- n:

  number of elements to keep counting from the beginning

- as_numeric:

  try to convert to numeric
