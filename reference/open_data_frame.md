# Assemble data frame from dataset

Assemble data frame from dataset

## Usage

``` r
open_data_frame(which, variables, observations, dataset, ...)
```

## Arguments

- which:

  specific name of data type

- variables:

  selected variables

- observations:

  selected observations

- dataset:

  dataset name

- ...:

  additional arguments for open_data()

## Value

a lazy Arrow connection to the assembled data frame
