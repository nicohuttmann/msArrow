# Add observations data to data frame

Add observations data to data frame

## Usage

``` r
add_observations_data(data, which, by = "observations", dataset)
```

## Arguments

- data:

  data frame

- which:

  observations data columns to add

- by:

  column of the observations data to join on (default "observations")

- dataset:

  dataset

## Value

the data frame with the requested observations data columns added
